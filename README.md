# vedansh1233.github.io

Personal portfolio and resume site of **Vedansh Trivedi**, Java full stack developer.

Live at **https://vedansh1233.github.io**

It's plain HTML and CSS with no build step, so GitHub Pages serves it straight from `main`.

## Edit

- Content: `index.html`
- Styles: `styles.css` (follows the system's light/dark theme; has a print stylesheet so the page also prints as a resume)
- Screenshots of the featured project: `assets/`

To preview locally, open `index.html` in a browser, or run `npx serve .`.
