Featured project

FX Desk: a full stack forex trading platform

A paper-trading app: sign up, receive a virtual $10,000 wallet, follow European Central Bank exchange rates and convert between 8 major currencies. Built end to end, from database schema to UI.

Backend · Spring Boot

  • REST API with Java 21 and Spring Boot 3.5, documented with OpenAPI / Swagger UI
  • Stateless auth with Spring Security and JWT; BCrypt passwords; consistent JSON error responses
  • Safe money handling: BigDecimal, a pessimistic row lock so concurrent trades can't overspend, rounding down so no money is created
  • Live ECB rates with caching and a graceful fallback when the rates provider is down
  • PostgreSQL with JPA/Hibernate; immutable transaction ledger with pagination
  • 31 automated tests: MockMvc integration tests on H2 plus unit tests for the cache logic

Frontend · React

  • React 19 + TypeScript (strict) with Vite and Tailwind CSS
  • Server state with TanStack Query; typed API client that mirrors the backend DTOs
  • Interactive SVG chart built from scratch: crosshair tooltip, keyboard navigation, screen-reader table
  • Protected routes, session restore and automatic logout on an expired token
  • Field-level validation errors from the API; responsive layout down to phone width
