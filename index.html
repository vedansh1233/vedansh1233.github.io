Backend · Spring Boot

  • REST API with Java 21 and Spring Boot 3.5, documented with OpenAPI / Swagger UI
  • Real-time prices pushed over a WebSocket; live Coinbase and ECB data fetched in parallel on virtual threads, with caching and a labelled fallback when a source is down
  • Limit orders and price alerts matched by scheduled jobs; row locks and conditional updates so a fill and a cancel can never both win
  • Safe money handling: BigDecimal with per-asset precision (8 decimals for crypto), rounding down so no money is created, one ledger service for every balance change
  • Stateless auth with Spring Security and JWT; BCrypt passwords; consistent JSON error responses
  • PostgreSQL with JPA/Hibernate and Flyway migrations
  • 51 automated tests: MockMvc integration tests, a real WebSocket test, and unit tests for the fallback logic

Frontend · React

  • React 19 + TypeScript (strict) with Vite and Tailwind CSS
  • One shared WebSocket feeding the TanStack Query cache, with reconnect backoff and polling fallback; prices flash as they tick
  • Interactive SVG charts built from scratch: crosshair tooltip, keyboard navigation, screen-reader table
  • Forex toolkit: pip value, position size and profit/loss calculators, cross-rate matrix, currency strength and correlation
  • Notification bell and toasts for triggered alerts; protected routes and session restore
  • Field-level validation errors from the API; responsive layout down to phone width
